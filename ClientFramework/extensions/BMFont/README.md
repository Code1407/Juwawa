# BMFont Generator

BMFont Generator is an extension for generate bitmap fonts.

## Introduction

Merge character images to generate .fnt files. Support drag-and-drop operation, one-click generation of bitmap fonts.

## Tutorial

- Click "Extension -> BMFont Generator" to open the main window
- Drag and drop the image file in the file to the specified area
- Click [Save] to generate a bitmap font file
- Click [Clear] to clear the currently added image
- Click [X] to remove the corresponding image
